Модуль `state-snapshotter` — критически важный инфраструктурный компонент Deckhouse Platform, предназначенный для
создания и восстановления снимков состояния ресурсов Kubernetes. Его используют другие компоненты Deckhouse Platform,
которым требуется работать со снимками состояния.

## Основные возможности

Модуль позволяет:

- захватывать состояние ресурсов Kubernetes в неймспейсе, включая кастомные ресурсы, ConfigMap, Secret и другие объекты;
- сохранять захваченное состояние для последующего чтения и восстановления;
- разбивать большие объёмы сохраняемых данных на чанки;
- восстанавливать ресурсы из ранее созданного снимка;
- управлять сроком хранения и очисткой данных снимка;
- использовать снимки при резервном копировании, аварийном восстановлении и миграции состояния между кластерами;
- предоставлять другим компонентам Deckhouse Platform механизм захвата и восстановления состояния ресурсов.

## Как работает модуль

Для создания снимка в нужном неймспейсе пользователь создаёт объект Snapshot. Модуль определяет объекты, которые должны войти в
снимок, захватывает их состояние и сохраняет результат для последующего чтения или восстановления.

## Ограничения

Модуль захватывает ресурсы своего неймспейса. Из cluster-wide-ресурсов захватывается только Namespace.

{{< alert level="warning" >}}
Не отключайте модуль `state-snapshotter`: его используют другие компоненты Deckhouse Platform, которые работают со
снимками состояния.
{{< /alert >}}
